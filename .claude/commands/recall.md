Read `LEARNING-LOG.md` and the code already built. Ask three short questions about earlier steps, one at a time, waiting for each answer:
1. What does a piece of code do?
2. Why is something built one way rather than an obvious alternative?
3. What would break if something were changed?

Favour anything he logged as confusing. After each answer, give brief feedback and correct any misunderstanding.
